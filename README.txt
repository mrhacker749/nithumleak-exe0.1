NITHUM.EXE — Birthday Website
================================

A playful fake-terminal prank that turns into a birthday surprise for Yush.
Made by Anuda. Birthday: 16 November 2026.

QUICK START
-----------
1. Extract this ZIP.
2. Open index.html in Chrome to preview the website.
3. Add your own media using the exact filenames below.
4. Add an audio file if you want background music.
5. Test everything before publishing.

ADD YOUR PHOTOS
---------------
Put your 5 photos inside:
assets/photos/

Rename them exactly:
memory-01.jpg
memory-02.jpg
memory-03.jpg
memory-04.jpg
memory-05.jpg

If your photos are PNG, either convert them to JPG or update the matching
image filename in index.html.

ADD YOUR VIDEOS
---------------
Put your 3 videos inside:
assets/videos/

Rename them exactly:
memory-video-01.mp4
memory-video-02.mp4
memory-video-03.mp4

MP4 (H.264 video + AAC audio) is the safest format for browser playback.
Keep videos reasonably compressed so the GitHub repository does not become
too large. GitHub has file and repository size limits.

ADD MUSIC (OPTIONAL)
--------------------
Put a music file at:
assets/music/soundtrack.mp3

The music player has a play button because browsers generally block autoplay.
Use music you have permission to use. If you do not add the file, the site
still works; the music button will simply have nothing to play.

CUSTOMISE CAPTIONS
------------------
Open index.html in a text editor and search for:
Exhibit A, Exhibit B, etc.
Replay 01, Replay 02, etc.

Change those captions to match your real memories.

PUBLISH WITH GITHUB PAGES
-------------------------
1. Sign in to GitHub and create a NEW PUBLIC repository, for example:
   nithum-birthday-2026
2. Upload the contents of this extracted folder (not the ZIP itself).
   Make sure index.html is in the repository's root.
3. Open the repository's Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and / (root), then Save.
7. Wait for GitHub Pages to publish. The site URL will appear in the Pages
   section, usually like:
   https://YOUR-USERNAME.github.io/nithum-birthday-2026/

IMPORTANT
---------
- This is a visual prank only. It does not hack, scan, infect, or access
  anyone's device, files, camera, or accounts.
- The name entered on the identity screen is used only in the browser and
  is not sent or saved anywhere.
- GitHub Pages websites are public. Do not add private conversations or
  photos/videos unless everyone shown is comfortable with them being shared.
- Anyone with the website link may be able to view the uploaded media.
- Test the site on a phone as well as a computer before sharing it.
